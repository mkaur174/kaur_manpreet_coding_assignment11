# kaur_manpreet_coding_assignment11

This project sets up a React web application running inside a Docker container.

## Overview
- **React App**: Displays `<h1>Codin 1</h1>` on the web page.
- **Working Directory**: Configured as `/kaur_manpreet_site` inside the container.
- **Container Name**: Set to `kaur_manpreet_coding_assignment11`.
- **Local Address**: Runs locally at `http://localhost:7775`.
